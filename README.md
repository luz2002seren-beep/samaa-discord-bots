# سماع — بوت موسيقى Discord عربي

بوت TypeScript بأوامر بلا بادئة، مبني فوق **NodeLink v3** عبر Shoukaku. يدعم البحث وروابط YouTube وروابط وقوائم Spotify من دون إضافة مصدر منفصلة.

## الأوامر

| الأمر | النتيجة |
| --- | --- |
| `ش <اسم أو رابط>` | تشغيل/إضافة أغنية أو قائمة إلى الطابور |
| `س` | تخطي الأغنية الحالية |
| `و` | إيقاف التشغيل ومسح الطابور ومغادرة الروم |
| `صوت <0-200>` | تغيير مستوى صوت الموسيقى |
| `ستريمنغ <النص>` | تغيير النص الظاهر في حالة Streaming (للمشرف) |
| `وضعية` أو `حالة` | عرض الأغنية الحالية وعدد عناصر الطابور |
| `ثتبيت #روم` أو `تثبيت #روم` | تعيين روم أوامر البوت (للمشرف) |
| `afk [سبب]` | تعيين حالة AFK لك أو إلغاؤها عند تكرار الأمر |
| `قائمتي إنشاء <اسم>` | إنشاء بلاي ليست خاصة بك |
| `قائمتي إضافة <اسم> <رابط/بحث>` | إضافة عنصر للقائمة الخاصة |
| `قائمتي تشغيل <اسم>` | تشغيل القائمة الخاصة |
| `قائمتي عرض [اسم]` | عرض قوائمك أو محتويات قائمة |

تظهر للبوت حالة **Streaming** في Discord، بينما التشغيل الصوتي الفعلي يتم داخل الروم الذي تدخل إليه.

## التشغيل

1. ثبّت Node.js 20+ للبوت وDocker لـNodeLink، ثم انسخ `.env.example` إلى `.env` وضع التوكن وكلمة مرور NodeLink ومفاتيح Spotify.
2. شغّل محرك الصوت: `docker compose up -d`. يستخدم المشروع صورة NodeLink v3، مع clustering تلقائي وفق الأنوية المتاحة ودعم Spotify المدمج.
3. ثبّت الحزم ثم شغّل البوت:

```bash
npm install
npm run dev
```

فعّل في Discord Developer Portal: `Message Content Intent` و`Server Members Intent`. امنح البوت صلاحيات View Channels وSend Messages وConnect وSpeak وEmbed Links.

> تنبيه: لا يحمّل هذا البوت ملفات صوت؛ NodeLink والمصادر التي تضبطها أنت مسؤولة عن الإتاحة والامتثال لشروط المنصات.
